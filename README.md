# Trillo Project

A responsive hotel booking landing page built with HTML and Sass. The project showcases a modern UI layout for a travel booking experience, including a searchable header, hotel overview, reviews, and a polished sidebar navigation.

## Features

- Responsive layout for desktop and mobile screens
- Modern booking app-style UI
- Sidebar navigation with interactive styling
- Hotel gallery, overview, and testimonial sections
- Sass-based styling workflow

## Technologies Used

- HTML5
- CSS3 / Sass
- Node.js
- NPM scripts for Sass compilation and live preview

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Run the Project

Start the development server and watch Sass files:

```bash
npm start
```

This will launch the project with live-server and compile Sass automatically.

### Build CSS

To compile and optimize the stylesheet:

```bash
npm run build:css
```

## Project Structure

- index.html – Main HTML file
- sass/ – Sass source files
- css/ – Compiled CSS files
- img/ – Images and SVG assets
